# Трекер задач: локальный markdown в `docs/plans/`

Тикеты и спецификации (спецификация = PRD) живут файлами в `docs/plans/` — там же,
где планы работ. Отдельного `.scratch/` завод не заводит: три хранилища планов
вместо одного (`docs/plans/`, `proposals/`, `.scratch/`) неизбежно расходятся,
а тикеты по правилу №4 должны версионироваться как evidence.

## Конвенции

- Одна фича — один каталог: `docs/plans/<ГГГГ-ММ-ДД-фича>/`
- Спецификация — `docs/plans/<фича>/spec.md`
- Тикеты реализации — по файлу на тикет:
  `docs/plans/<фича>/issues/NN-<slug>.md`, нумерация с `01` в порядке зависимостей
- Состояние триажа — строка `Status:` в начале файла тикета
  (строки ролей — `docs/agents/triage-labels.md`); терминальное состояние
  реализованного тикета — `done` (после него правится только `## Комментарии`),
  провален после ретрая — `failed`
- Комментарии и история обсуждения — в конце файла под заголовком `## Комментарии`

Одиночный план без тикетов остаётся плоским файлом `docs/plans/<дата>-<фича>.md`,
как сейчас. Каталог заводится только тогда, когда работа режется на тикеты.

## Когда скилл говорит «опубликовать в трекер»

Создать файл в `docs/plans/<фича>/` (каталог — при необходимости).

## Когда скилл говорит «прочитать тикет»

Прочитать файл по указанному пути. Обычно путь или номер даёт человек.

## Операции wayfinder

Используются скиллом `/wayfinder`. **Карта** — файл, у каждого тикета свой файл.

- **Карта**: `docs/plans/<фича>/map.md` — разделы Destination / Notes /
  Decisions-so-far / Not yet specified / Out of scope.
- **Тикет**: `docs/plans/<фича>/issues/NN-<slug>.md` с вопросом в теле.
  Строка `Type:` — тип тикета (`research`/`prototype`/`grilling`/`task`),
  строка `Status:` — `claimed`/`resolved`.
- **Блокировки**: строка `Blocked by: NN, NN` в начале файла. Тикет разблокирован,
  когда все перечисленные файлы в состоянии `resolved`.
- **Фронтир**: файлы в `docs/plans/<фича>/issues/`, которые открыты,
  разблокированы и никем не заняты; первый по номеру побеждает.
- **Занять**: выставить `Status: claimed` и сохранить ДО начала работы.
- **Закрыть**: дописать ответ под заголовком `## Ответ`, выставить
  `Status: resolved`, добавить строку-указатель в Decisions-so-far карты.

## Границы, которые трекер не отменяет

- Правки промптов идут не тикетом, а аппликатором (правило №3):
  `cf apply-brief-prompt`, `cf apply-prompt-candidate`, `cf apply-agent-edit`.
  Запись в `prompts/**` и `.claude/commands/**` закрыта deny-правилами харнесса.
- Предложения по источникам и промптам — `proposals/`, не `docs/plans/`.
- Рантайм-артефакты (скриншоты, отчёты, дампы) — `agent-runtime/`, правило №4.
