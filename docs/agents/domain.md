# Доменные документы

Что скиллы читают, прежде чем лезть в код, и каким словарём пользуются.

## Читать до начала работы

Завод — репозиторий с одним контекстом. `CONTEXT.md` и `docs/adr/` в корне
**отсутствуют намеренно**: их роль уже занята.

- **`CLAUDE.md`** — правила системы, инструменты, ворота конвейера. Первый файл.
- **`docs/BUSINESS-CONTEXT.md`** — чей это бренд и для кого контент.
- **`prompts/agents/niche-taxonomy.json`** — единственный источник истины по нишам.
- **`.claude/memory/decisions/`** + строка-указатель в `.claude/memory/MEMORY.md` —
  журнал принятых решений. Это ADR завода: каждое решение датировано,
  с обоснованием и способом отката.
- **`formulas/_decisions.jsonl`** — append-only журнал решений по рецептам
  (`human`/`auto`), машинная часть того же журнала.

Отсутствие `CONTEXT.md` не флагать и не предлагать его завести: словарь домена
живёт в `CLAUDE.md`, и раздваивать его — способ получить два расходящихся
описания одного завода.

## Пользоваться словарём завода

У завода два словаря, и путать их нельзя.

- **Внутренний (код, тикеты, коммиты)**: ниша, формула, бриф, паттерн, prompt_version,
  reel_id, ворота, фан-аут.
- **Продюсерский (всё, что видит пользователь дашборда)**: тема, рецепт, сценарий,
  промпт темы, шаг. Инвариант «в видимом тексте продюсерских разделов нет системного
  жаргона» проверяется тестами в `tests/test_dashboard_routes.py`.

Называя доменное понятие в тикете, гипотезе или имени теста — брать внутренний
словарь. Называя его в тексте интерфейса — продюсерский. Синонимы не изобретать:
третья копия признака «готова ли тема» однажды уже стоила заводу 10 из 14
утверждённых рецептов, которые молча не давали сценариев.

## Конфликт с принятым решением

Если вывод противоречит записанному решению — сказать это прямо, а не
переписывать молча:

> _Противоречит решению 26.07 «Машинные ворота» — но стоит переоткрыть, потому что…_

Ключ связей, по которому сходится вся предметная область:
`source_url → pattern_id → formula_id → brief_id → prompt_version → reel_id → performance`.
