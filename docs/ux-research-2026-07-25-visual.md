## Вердикт в одну строку

**На десктопе дизайн реально хороший** — чистая иерархия, аккуратные карточки, читаемый конвейер (см. `overview-1280-fold.png`). **Но на мобильном/планшете он ломается системно: в стилях нет ни одного layout-медиазапроса.** Это главная нетто-новая находка визуального аудита; code-аудит её показать не мог.

## Находки (нетто-новое к code-аудиту)

### [HIGH] Дашборд не адаптивен вообще — нет ни одного брейкпоинта
`src/cf/dashboard/static/style.css` — единственный `@media` во всём файле про `prefers-reduced-motion` (строка 117). Каркас жёстко десктопный и не перестраивается:
- `.shell { display:flex }` + `.sidebar { width:240px; height:100vh }` (:29,:33) — **сайдбар-меню не сворачивается никогда**; на 375px тёмная колонка съедает ~⅓ экрана (см. `sources-375.png`, `runs-375.png`).
- `.stat-row { grid-template-columns: repeat(4,1fr) }` (:67) — 4 KPI-карточки всегда в один ряд; на 375px они сжаты до ~90px, подписи ломаются (`overview-375.png`).
- `.briefs-layout { 1fr 430px }` (:163), `.two-col { 1fr 1fr }` (:73), `.stage-row { flex }` (:76) — всё фиксировано, на узком экране крошится.

**Почему важно продюсеру:** он мобильный пользователь (проверить очередь съёмки, глянуть брифы с телефона на площадке). Сейчас с телефона сервис фактически непригоден. **Fix:** добавить брейкпоинты — <1024px: сайдбар в верхнюю панель/бургер, `.briefs-layout`/`.two-col` → 1 колонка; <768px: `.stat-row` → 2, затем 1 колонка, `.stage-row` → перенос/горизонтальный скролл.

### [HIGH] Таблично-тяжёлые разделы непригодны ниже ~1024px
«Источники», «Запуски», «Performance», таблицы «Брифов» на 375/768 зажаты в неколлапсящийся каркас, а `.card` таблиц имеет инлайновый `overflow:hidden` (см. code-аудит) → правый край обрезан, текст микроскопический (`sources-375.png`, `runs-375.png`). **Fix:** `.card--table { overflow-x:auto }` вместо инлайнов (уже в бэклоге code-аудита) + после коллапса сайдбара таблицы получают ширину; для 375px рассмотреть fallback «строка-карточка» вместо горизонтального скролла 8–9 колонок.

### [MED] «Лаборатория» — перегруженная стена текста
`lab-375.png` — страница ~21 000 px в высоту: карточки очереди формул выводят полный текст проблемы/формата/условий (после снятия обрезки 2026-07-25 — оправданно для решения оператора, но убивает сканируемость), плюс лента отчётов. На мобильном — бесконечный скролл. **Fix (баланс с прошлой правкой):** длинные описательные поля показывать свёрнутыми (`line-clamp` + «показать полностью»/`<details>`), сохраняя полный текст по запросу — не возвращать жёсткую обрезку. На десктопе тоже улучшит сканируемость очереди.

### [MED] «Обзор»: KPI-карточки и плитки конвейера не стекируются
`overview-375.png` — 4 стат-карточки и лента плиток конвейера сжаты в один ряд, подписи вроде «БРИФЫ ЖДУТ ВНИМАНИЯ» переносятся некрасиво, номера плиток нечитаемы. Часть общей проблемы адаптивности, но «Обзор» — первый экран, поэтому вынесено отдельно.

## Визуально подтверждено (уже в code-аудите — тут видно глазами)
- Плитки конвейера подписаны инструментами: на `overview-1280-fold.png` читается «N8N», «CLAUDE CODE», «ПРОДЮСЕР · N8N» — стек, а не роли.
- Первая метрика «RAW В БАЗЕ · ПЕРИОД» и рассинхрон имён «Raw-ролики» (плитка) ↔ «Источники» (меню) — видно на том же кадре.
- Водяной знак-логотип от `.empty-state::before` — на `overview-375.png` под «Engagement rate по неделям» (тут уместно — настоящая пустота; проблема в том, что тот же класс рисует логотип под ошибками/пагинацией, см. code-аудит).

## Что это меняет в плане работ

Визуальный аудит добавляет к последовательности из code-аудита **один крупный блок — адаптивность**, и уточняет одну прошлую правку:

- **Новый приоритет: адаптивная вёрстка** (брейкпоинты + коллапс сайдбара + стекирование карточек + скролл/переверстка таблиц). По эффекту для продюсера-с-телефона — высокий; по усилию — средний (правки в одном `style.css` + мелочь в `base.html` для бургер-меню).
- **Уточнение:** снятие обрезки в очереди «Лаборатории» (коммит 246984a) сделать через `line-clamp` + разворот, а не полный вывод — иначе страница превращается в стену.
- Десктопный дизайн **не трогать по сути** — он хорош; вся работа это адаптив + контент/язык из code-аудита, не редизайн.

**Оговорка честности:** стена текста в «Лаборатории» — отчасти следствие моей же правки обрезки ранее сегодня. Правильно закрыть её `line-clamp`-ом, сохранив полный текст для решения оператора.
