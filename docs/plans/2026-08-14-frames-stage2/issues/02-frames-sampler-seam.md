## Что построить

Выборщик кадров — отдельный шов vision-звена: интерфейс «кадры строки с
номерами + кап + метаданные манифеста → подмножество путей с исходными
номерами». Реализации живут в реестре по образцу реестра движков vision;
стратегия выбирается ключом конфига `vision.frames_sampler` (дефолт —
`uniform`), неизвестная стратегия — громкий отказ конфигурации, а не тихий
фолбэк. Новая стратегия выборки в будущем стоит строку конфига, а не
переделку звена.

Стратегия `uniform` — единственная в этапе 2: детерминированная равномерная
субвыборка, первый и последний кадры обязательны, кап не превышается; кадров
меньше либо равно капу — подаются все. Исходные номера кадров сохраняются,
чтобы `frame:N` в фактах всегда указывал на реальный файл на диске.

## Критерии приёмки

- [ ] Детерминизм: одинаковый вход → одинаковая выборка.
- [ ] Первый и последний кадры всегда в выборке; кап не превышается;
      «кадров ≤ капа → все».
- [ ] Выборка несёт исходные номера кадров (не переиндексируется с 1).
- [ ] Стратегия берётся из `vision.frames_sampler`, дефолт `uniform`;
      неизвестное значение — громкий отказ с перечнем доступных стратегий.
- [ ] Тесты шва не зовут движок, Sheets и файловую систему медиа сверх
      необходимого (чистая логика выборки).
