Решение №4 гриля: один агент, имя не меняется.

## Что построить

`vision-cover` расширяется на кадры машинным путём: черновик в `proposals/`
+ `cf apply-agent-edit` (прецедент — тикет 09 v1). Имя агента и файла не
меняется; напрямую в `prompts/**` этот тикет не пишет (правило №3).

Дополнения контракта честности:

- с кадрами МОЖНО судить о сменах сцен, структуре и видимом финале;
- ЗАПРЕЩЕНО утверждать движение, темп монтажа и события «между кадрами»
  (кадры — не видео);
- при субвыборке судить только по поданным кадрам;
- в `unsupported_visual_claims` кадрового режима — что по субвыборке кадров
  утверждать нельзя (музыка, темп, микро-события).

Там же — правила заполнения новых полей (`narrative_structure`,
`cta_visual`, `frames_analyzed`) и чтения строки метаданных подачи
(сколько кадров из скольких, длительность, правило нумерации).

## Критерии приёмки

- [ ] Черновик расширения лежит в `proposals/` с evidence-обоснованием
      (ссылка на спеку и рамку гриля).
- [ ] Промпт применён через `cf apply-agent-edit`, версия зафиксирована
      машинным путём; ручной записи в `prompts/**` не было.
- [ ] Контракт честности содержит запрет движения «между кадрами» и правило
      субвыборки; правила заполнения трёх новых полей согласованы со схемой
      (тикет 03).
- [ ] Cover-режим промпта не деградирует: без кадров агент работает
      по-прежнему (кадровые поля не требуются).
