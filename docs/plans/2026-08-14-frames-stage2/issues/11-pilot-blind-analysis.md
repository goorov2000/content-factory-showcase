## Что построить

Слепое сравнение, отвечающее на вопрос «дают ли кадры анализу больше, чем
обложки»: два прогона анализа ОДНОГО батча — «факты обложек» против «фактов
с кадрами» (корпус тикета 10), запечатанный ключ соответствия, раскрытие
только после предварительного ответа — механика ступени 3 пилота v1
(прецедент: слепое А/Б обложек 14.08).

Итог — артефакт в `agent-runtime/analysis/` человеческим текстом: зачем
сравнивали, как устроена слепота, что показали прогоны (различия паттернов,
опора на структуру и финал, честность ссылок), точные числа в приложение,
вопрос оператору на вердикт с критерием простыми словами.

Вердикт оператора = `frames_enabled=true` (одна строка конфига после его «да»).
Включение `vision.in_cycle` — ОТДЕЛЬНОЕ решение при расконсервации завода,
не этот тикет. Отрицательный вердикт тоже легален: кадры остаются
выключенными, evidence лежит в артефакте.

## Критерии приёмки

- [ ] Ключ соответствия запечатан до прогонов; раскрытие зафиксировано после
      предварительного ответа (механика ступени 3 v1 воспроизведена).
- [ ] Оба прогона анализа выполнены на одном батче; в Run Log с
      `--started-at`.
- [ ] Артефакт сравнения человеческим текстом с вопросом на вердикт.
- [ ] Вердикт оператора записан (тикет + память решений); при «да» —
      `frames_enabled=true` в конфиге, `vision.in_cycle` не тронут.
