# 01 — Публикация с аккаунтом

**What to build:** У завода появляется реестр своих аккаунтов, и публикация
ролика привязывается к аккаунту. В `cf.config.json` — верхнеуровневый ключ
`accounts` (список `{slug, platform, handle, active}`; пустой список — валидное
состояние «аккаунты не заведены»). В очереди съёмки пульта рядом с «Отдал в
работу» появляется форма «Опубликован» (URL + select аккаунта + заметка) — та
же, что уже есть на карточке сценария; обе формы получают select аккаунта.
`cf mark-published` получает `--account` с валидацией по реестру; строка в
CF Published Reels несёт новую колонку `account`. При пустом реестре формы
публикации показывают причину («реестр аккаунтов пуст — заполни accounts в
cf.config.json»), а не прячутся молча — образец: пустые `creator_slots`.

**Blocked by:** None — can start immediately.
