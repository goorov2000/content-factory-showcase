# 04 — Страница «Деньги» и расчётный лист

**What to build:** В пульте появляется вкладка «Деньги» (`/money`) — общая
правда владельца и продюсера. Секции: (1) «Расчётный лист» за выбранный месяц
— уники по аккаунтам × `payout.per_transition_rub` + подтверждённая выручка ×
`payout.sales_percent`, заказы моложе `payout.hold_days` — строкой «в холде,
войдёт в следующий лист», опциональный фикс из `payout.monthly_fix_rub`;
(2) «Переходы по аккаунтам» за месяц; (3) «Заказы» — сюда переезжают кнопки
статусов и форма ручного заказа из тикета 03; (4) «Ссылки для bio» — готовые
UTM-ссылки по каждому активному аккаунту и конструктор per-reel ссылки
(`utm_content=<reel_id>`). Экспорт `?format=md` отдаёт расчётный лист
markdown'ом. Сноска «контур меряет нижнюю границу вклада роликов» — в шаблоне
листа и в экспорте, безусловно. Расчёт — чистые функции (время и данные
аргументами, без побочек); ставки — только из `cf.config.json → payout`,
в коде констант нет.

**Blocked by:** 01 (реестр аккаунтов), 02 (переходы), 03 (заказы).

**Status:** done

- [x] `/money` рендерится при пустых вкладках (нулевой месяц — это состояние,
  а не ошибка) и при пустом реестре аккаунтов (причина вместо секций).
- [x] Лист: уники берутся из месячных строк (не суммой дневных), холд
  отрабатывает по дате заказа относительно момента формирования, возвраты и
  rejected в выручку не входят.
- [x] `?format=md` — валидный markdown с теми же числами и сноской; пригоден
  для пересылки продюсеру как есть.
- [x] Генератор ссылок собирает URL из `site.base_url` + UTM-конвенции по
  каждому активному аккаунту; неактивные не показываются.
- [x] Кнопки заказов и ручная форма работают со страницы «Деньги» (редирект
  обратно на неё), временный раздел тикета 03 удалён.
- [x] Тесты: чистая функция листа (граничные: пустой месяц, заказ в холде,
  возврат, фикс задан/не задан), роут, md-экспорт, генератор ссылок.
  Полный сьют зелёный.
