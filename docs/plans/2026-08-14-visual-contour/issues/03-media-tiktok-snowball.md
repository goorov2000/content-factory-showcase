## Что построить

`cf collect tiktok` (и snowball — он идёт TikTok-трактом по построению) после
гейта скачивает обложку И видео каждой прошедшей строки, режет кадры, удаляет
сырец и кладёт в строку манифест с честным статусом. Скоропортящиеся ссылки
перестают быть точкой невозврата.

- Приём — существующий шов субтитров: параллельный пул, инжектируемый
  скачивальщик, та же политика ретраев. Скачивание v1 — прямой HTTP GET по
  `thumbnail_url`/`video_url` из выдачи актора; токен Apify подписывает
  только запросы к api.apify.com (правило №5). Платная надбавка Apify
  video-download в v1 не включается (запасной путь, решение по метрике
  пилота — тикет 10).
- Нарезка детерминированная: ffmpeg, 1 кадр/сек, потолок 60 кадров, первый
  кадр обязателен, JPEG. Нарезчик инжектируем — реальный ffmpeg в тестах
  не зовётся.
- Хранение: `agent-runtime/media/<platform>/<raw_id>/` — `cover.jpg` и
  `frames/NNN.jpg` (правило №4, не версионируется). Сырое видео — во
  временный файл того же каталога, удаляется сразу после нарезки.
- Скачивание — всем прошедшим гейт строкам, без фильтров по просмотрам/нише
  (решение гриля №2).

## Критерии приёмки

- [ ] Строки после сбора несут `media_status` (saved | partial | failed |
      пусто) и `media_manifest` (компактный JSON: относительные пути
      обложки/кадров, число кадров, признак удаления сырца) — имена
      канонические по спеке, column_aliases не нужны.
- [ ] Сырое видео удалено после нарезки, в том числе при ошибке нарезки;
      статус честно фиксирует частичность (partial — обложка есть, видео/кадров
      нет; failed — ничего).
- [ ] Отказ скачивания медиа не валит сбор строк и не деградирует статус
      рана: медиа — обогащение, не условие сбора (правило №2 действует через
      счётчики, не через падение).
- [ ] dry-run качает и режет боевым режимом (механизм пилота), строки с
      media-полями идут только в JSONL, Sheets не трогается.
- [ ] Идемпотентность: `raw_id` с манифестом на диске повторно не качается.
- [ ] Пересбор строки без медиа не затирает ранее добытые media-поля
      (правило мержа «непустое побеждает пустое»).
- [ ] Счётчики медиа (скачано/кадров/отказов/протухших) — в сводке, stdout
      и Run Log; реестр ожидаемых колонок обновлён.
- [ ] Тесты — через существующий верхний шов `collect()` с
      fake-скачивальщиком, fake-нарезчиком, FakeSheets и tmp-каталогом вместо
      `agent-runtime/`; snowball покрыт тем же трактом.
