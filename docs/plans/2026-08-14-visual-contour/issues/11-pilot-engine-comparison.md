## Что построить

Один и тот же набор обложек батча пилота (тикет 10) прогоняется через 2+
конфигурации vision-движка (дефолт-гипотеза — headless Haiku против старшей
модели; при появлении API-ключа — третьей конфигурацией). Переключение —
только конфигом (решение гриля №4): сравнение движков — дело пилота, не кода.

Артефакт сравнения — в `agent-runtime/analysis/`: качество и честность
фактов (доля пустых `visual_evidence`, утечки гипотез в факты, нарушения
контракта честности), расход лимита подписки/денег на строку.

Финальное слово — оператора: его решение фиксирует дефолт `vision.engine` /
`vision.model` в конфиге. Агент готовит всё до этой точки и подаёт сравнение.

## Критерии приёмки

- [x] ≥2 конфигурации движка прогнаны по ОДНОМУ и тому же набору обложек;
      каждая смена — только строкой конфига; все прогоны в Run Log.
- [x] Артефакт сравнения содержит и качество/честность фактов, и расход —
      в числах, по каждой конфигурации (evidence-first).
- [x] Вердикт оператора получен и зафиксирован; выбранный дефолт выставлен
      в блоке `vision` конфига (приёмка тикета — за оператором).
