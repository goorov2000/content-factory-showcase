## Что построить

Промпт vision-движка появляется в заводе как новый агент, установленный
существующим машинным путём: черновик в `proposals/` в формате
`cf install-agent`, установка аппликатором. Ни одной прямой записи в
`prompts/**` (правило №3 — deny-правила и так это закрывают).

Промпт — то, что headless-движок (тикет 05) подаёт модели вместе с обложкой:
контекст строки, задание описать наблюдаемое и жёсткий контракт честности
из n8n-референса.

## Критерии приёмки

- [ ] Черновик proposal нового агента лежит в `proposals/` в формате, который
      принимает `cf install-agent`, с evidence (ссылка на спеку и
      n8n-референс «Радар трендов»).
- [ ] Промпт вшивает контракт честности: каждая запись `visual_evidence`
      ссылается на конкретное медиа; по одной обложке запрещено судить о
      музыке, монтаже, динамике, переходах, первых секундах, структуре сцен,
      CTA в движении; `observed_media: none` → визуальные выводы не делаются;
      гипотезы — только в `visual_hypotheses`.
- [ ] Промпт требует выход строго по схеме визуальных фактов (тикет 02).
- [ ] Установка выполнена `cf install-agent`; Codex-обёртки перегенерированы
      самим аппликатором (`cf codex-sync --check` чист); след в Run Log.
