## Что построить

Данные пилота: ручной `cf collect --dry-run` TikTok + Instagram (1 батч,
свежие ссылки, боевое скачивание медиа) — на паузе завода, таймеры не
трогаются (решение гриля №5). Выход: JSONL со строками, медиа на диске,
след в Run Log.

Метрика ступени: доля успешных ПРЯМЫХ скачиваний обложек и видео по
платформам — это основание решения о запасном платном пути Apify
video-download (включается только явным конфигом, решение оператора).

## Критерии приёмки

- [x] Оба dry-run прогнаны разово руками/агентом; ни один таймер не включался;
      платная надбавка video-download не включалась (расход — центы Apify).
- [x] JSONL и медиа лежат в `agent-runtime/`; оба прогона — в Run Log со
      `--started-at` (правило №6).
- [x] Артефакт в `agent-runtime/analysis/`: доли успешных скачиваний по
      платформам и типам медиа (обложка/видео), причины отказов.
- [x] Зафиксирована рекомендация по надбавке Apify с числами
      (evidence-first); само включение остаётся решением оператора.
