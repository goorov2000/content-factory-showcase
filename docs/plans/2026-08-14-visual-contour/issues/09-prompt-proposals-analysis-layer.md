## Что построить

Аналитический слой получает право видеть и использовать визуальные факты —
правками промптов только машинным путём (правило №3), ни одной прямой записи
в `prompts/**`:

1. **Анализатор паттернов**: правило верификации evidence расширяется —
   «по транскрипту, капшену ИЛИ визуальным фактам»; плюс явный запрет
   выдумывать визуал строкам с пустым `visual_facts` («не разобрано» ≠
   «фактов нет»).
2. **Formula-writer**: разрешение ссылаться на визуальные факты и класть
   `visual_refs` в evidence рецепта (машинная форма «кадр N видео X»).

Применение — существующий аппликатор правок агентных промптов
(`cf apply-agent-edit`).

## Критерии приёмки

- [ ] Оба proposal лежат в `proposals/` с evidence: ссылка на спеку и на
      слепоту анализатора (раздел «Визуал» — догадка по тексту).
- [ ] Применены аппликатором; прямых записей в `prompts/**` нет; след
      установки — в Run Log.
- [ ] Промпт анализатора после правки требует отличать «медиа не разобрано»
      от «фактов нет»; промпт formula-writer ссылается на форму `visual_refs`
      из схем (тикет 08).
