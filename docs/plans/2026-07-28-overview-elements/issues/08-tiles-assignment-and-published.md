# 08 — Плитки «Ждут назначения исполнителя» и «Опубликованы»

**Blocked by:** 06, 07
**Status:** ready-for-agent
**Type:** enhancement

ТЗ: [решения владельца](../../../design/2026-07-28-overview-elements.md),
элементы 7, 8 и 13 (строка старения — подписью в плитку). Этап 3 порядка работ.

## Что построить

Две плитки отвечают на вопросы, которые у продюсера действительно есть.

* **«Ждут назначения исполнителя»** вместо «СЦЕНАРИИ ЖДУТ ВНИМАНИЯ»: одобренные
  сценарии, у которых исполнитель не назначен. На данных 28.07 это 59 — а старая
  плитка показывала 0 и была права формально: все пять ждущих сценариев отложены
  заводом по капу рецепта, решать по ним человеку нечего. Правда была, но не вся.
  Подписью в этой же плитке — старение: сколько одобрено без съёмки дольше
  порога. Формулировка «доходят до съёмки за неделю» убирается совсем.
* **«Опубликованы»** вместо «ЖДУТ СТАТИСТИКИ»: ролики, получившие ссылку.
  Реальных сегодня 0 — 35 строк в снимке помечены как демо eval-петли и в счёт
  идти не должны.

Пустота здесь — не дефект, а правило №2: роликов снято 0, и показать это честно
важнее, чем спрятать плитку.

## Критерии приёмки

- [ ] «Ждут назначения» считает одобренные сценарии без исполнителя; назначенный
      из плитки уходит сразу
- [ ] подпись плитки несёт число старения; фразы «доходят до съёмки за неделю» на
      экране нет
- [ ] «Опубликованы» считает ролики со ссылкой и не считает демо-строки; есть
      тест, который ловит попадание демо в счёт
- [ ] окно счёта — то же скользящее окно 7 дней, что и у мини-плиток
- [ ] нулевые значения показываются честно, без скрытия плитки
- [ ] инварианты на старые заголовки плиток поправлены осознанно, а не подогнаны
- [ ] тесты зелёные
