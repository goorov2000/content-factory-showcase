# 09 — «Темп недели»: три полукольца

**Blocked by:** 06, 07
**Status:** ready-for-agent
**Type:** enhancement

ТЗ: [решения владельца](../../../design/2026-07-28-overview-elements.md),
элемент 9, плюс элементы 10–13 (счёт недели и конверсия переезжают сюда) и хвост
«Окно счёта колец». Этап 3 порядка работ.

## Что построить

На месте плитки «СРЕДНЯЯ ВОВЛЕЧЁННОСТЬ» — **«Темп недели»**: три вложенных
полукольца радугой, у каждого цель 70.

* внешнее — **одобрено**
* среднее — **назначен исполнитель**
* внутреннее — **выложено**

Живые числа на 28.07: 54 / 0 / 0. Конверсия читается как разница колец — отдельной
строки для неё больше нет.

Окно — **скользящие 7 дней** (то же, что у плиток). Календарная неделя давала
0/70 во вторник при 54 сценариях, одобренных в воскресенье.

Плитка занимает габарит обычной плитки в общей строке.

## Критерии приёмки

- [ ] три полукольца показывают одобрено / назначен исполнитель / выложено,
      каждое к цели 70
- [ ] числа считаются за скользящие 7 дней
- [ ] значение выше цели не рисует кольцо за пределы и не ломает габарит
- [ ] кольца доступны не только цветом: числа и подписи читаются текстом,
      скринридер называет каждое кольцо и его значение
- [ ] инвариант на заголовок «СРЕДНЯЯ ВОВЛЕЧЁННОСТЬ» поправлен осознанно
- [ ] тесты зелёные; снимок с живыми числами показан владельцу
